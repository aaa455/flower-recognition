# 五类花卉图像分类项目说明

仓库：https://github.com/aaa455/flower-recognition

## 问题与实现

给定一张花卉图片，在雏菊、蒲公英、玫瑰、向日葵和郁金香中预测类别，并输出候选分数。
使用 TensorFlow 发布的 flower_photos 数据，手动编写 ResNet-18，从随机参数开始训练。
项目采用命令行运行，包含数据下载、统计、清洗划分、训练验证、测试评估和单图推理。

| 模块 | 文件 | 主要职责 |
|---|---|---|
| 下载 | `src/download.py` | 下载并安全解压数据 |
| 分析 | `src/analyze.py` | 检查可读性、统计类别和尺寸、检测完全重复文件 |
| 清洗划分 | `src/prepare.py` | 排除冲突、去重、按类别划分训练/验证/测试集 |
| 数据加载 | `src/dataset.py` | Dataset、DataLoader、归一化及训练增强 |
| 网络 | `src/model.py` | 手动实现残差块和 ResNet-18 |
| 训练 | `src/train.py` | 计算损失、反向传播、验证、保存最佳权重及曲线 |
| 评估 | `src/evaluate.py` | 测试指标、混淆矩阵和错误记录 |
| 推理 | `src/predict.py` | 使用保存的类别顺序和预处理参数预测单张图片 |

完整安装和运行命令见 [README](../README.md)，录屏操作见 [运行演示](demonstration.md)。

残差块计算 `ReLU(F(x) + S(x))`。形状不变时 `S(x)` 直接返回输入；
下采样或改变通道数时，通过 1×1 卷积匹配形状。这使梯度拥有更直接的传播路径，帮助训练深层网络。
网络输出原始分数 logits，训练时直接使用交叉熵，展示预测时才计算 softmax。

迁移学习是复用其他数据上学到的参数。常见方法是替换分类层，先冻结特征提取层训练分类层，
再以较小学习率微调整个网络。它通常能减少小数据任务的训练成本，但效果取决于源任务与目标任务。
本项目从随机参数训练手写网络，预训练权重没有参与当前实验。

## 数据处理与实验结果

原始数据共 3670 张，检查发现 2 张标签冲突图片和 2 张同标签冗余图片，清洗后保留 3666 张。
按类别划分为 2572 张训练、547 张验证、547 张测试图片，种子为 42。
均值和标准差只由训练集计算，训练时增加随机水平翻转。

96×96 输入、batch size 16、Adam 学习率 0.001，训练 8 轮。
第 8 轮验证准确率最高，为 68.92%；该模型测试准确率为 67.46%，宏平均 F1 为 0.6584。
测试图片中 369 张正确、178 张错误。详细配置、原始指标和图表见 [实验报告](experiment-report.md)。

这些结果表明模型学到了部分分类特征，但识别仍不稳定。玫瑰召回率只有 34.38%，
其中 30 张玫瑰被误识别为郁金香。不能仅凭某张图片预测成功就判断整体效果良好。

## 实现中的处理与局限

- 字节完全相同的文件只保留一份，跨标签冲突排除整个组，减少重复内容跨集合造成的信息泄漏。
- 模型保存类别、归一化参数、配置和划分哈希，推理复用相同设置，评估核对划分清单。
- 新实验和预测记录使用新路径，避免覆盖旧记录，便于比较和排查问题。
- 测试指标包含各类表现和逐图错误记录，便于发现整体准确率掩盖的问题。

这仍是一次固定划分与随机种子的实验。图片缩小可能损失细节，去重没有覆盖视觉近似图片，
也尚未系统验证自行拍摄图片、未知花种和非花卉输入。
后续可依据验证集比较输入尺寸、数据增强与学习率调度；
如果持续查看当前测试错误并改进方案，应另留独立数据用于最终检验。
