# 手写 ResNet-18

使用 PyTorch 的基础层实现卷积、批归一化、激活和池化，自己编写残差块并组装网络。
没有调用现成的 ResNet，也没有加载预训练参数。

## 残差块

主分支的顺序是：3×3 卷积 → BatchNorm → ReLU → 3×3 卷积 → BatchNorm。
捷径分支绕过这两次卷积，在末尾与主分支逐元素相加，再经过 ReLU。

```text
输入 x ── 卷积 → BN → ReLU → 卷积 → BN ──┐
   └──────────── 捷径 S(x) ───────────────┤ 相加 → ReLU → 输出
```

输出为 `ReLU(F(x) + S(x))`。F(x) 表示主分支结果，S(x) 表示捷径结果。
残差连接为信号和梯度提供更直接的传播路径，有助于深层网络优化，但不保证每个任务都提高准确率。

两条分支的形状必须一致。当通道数相同且步长为 1 时，捷径使用 `Identity`，直接返回 x。
当通道数改变或步长为 2 时，捷径使用 1×1 卷积和 BatchNorm，将形状调整为与主分支一致。
例如 `[N,64,24,24]` 变成 `[N,128,12,12]` 时，捷径也需要改变通道数并下采样。

## 网络形状

默认输入尺寸为 96×96，N 表示批次大小。

| 位置 | 输出形状 | 作用 |
|---|---|---|
| 输入 | `[N,3,96,96]` | RGB 图片 |
| stem | `[N,64,24,24]` | 初始卷积与池化 |
| layer1 | `[N,64,24,24]` | 两个残差块 |
| layer2 | `[N,128,12,12]` | 两个残差块，首块下采样 |
| layer3 | `[N,256,6,6]` | 两个残差块，首块下采样 |
| layer4 | `[N,512,3,3]` | 两个残差块，首块下采样 |
| 全局平均池化 | `[N,512,1,1]` | 每个特征通道压缩为一个数 |
| 展平 | `[N,512]` | 保留批次维度 |
| 分类层 | `[N,5]` | 五个花卉类别的原始分数 |

输入只有 3 个颜色通道；后续 64、128 等通道是网络学习的特征，不再分别表示红、绿、蓝。
标准计数为：初始 1 个卷积 + 8 个残差块中的 16 个卷积 + 最后的 1 个线性层，共 18 层。
捷径的投影卷积不计入这个名称中的层数。

## 输出与模式

网络输出 logits，即尚未归一化的类别分数，训练时直接交给 `CrossEntropyLoss`。
需要展示预测分数时，再在推理阶段计算 softmax。
类别顺序与数据加载一致：雏菊、蒲公英、玫瑰、向日葵、郁金香。

BatchNorm 在训练时使用批次统计，在评估时使用积累的统计量，因此训练使用 `model.train()`，评估使用 `model.eval()`。
批次大小为 1 且最后特征图只有 1×1 时，训练模式下 BatchNorm 会缺少足够样本，训练流程需要处理这种情况。

`python -m src.model` 只用随机输入检查形状，随机初始化的网络不能用于花卉识别。
