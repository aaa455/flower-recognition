# 单张图片预测

训练后保存的 `best.pt` 可以反复用于预测，不需要每次重新训练。
预测只需要权重和待预测图片，不需要数据集、训练清单或真实标签。

```powershell
.\.venv\Scripts\python.exe -m src.predict --checkpoint runs/experiment-01/best.pt --image "C:/photos/flower.jpg"
```

将两个路径替换为实际文件路径。包含空格的路径使用双引号。
默认显示前三个候选，`--top-k 1` 只显示第一候选，最多显示五个。
可以用 `--output runs/predictions/flower.json` 保存结果；已有输出文件不会覆盖。

## 从图片到类别

1. 载入权重，按训练时的类别数量重建 ResNet-18。
2. 读取图片并转换为 RGB，灰度图和带透明通道的图片也会转换为三个通道。
3. 使用权重里记录的输入尺寸、均值和标准差预处理，不做随机翻转。
4. 添加批次维度：`[3,H,W]` 变为 `[1,3,H,W]`。
5. 切换到评估模式并关闭梯度计算，得到五个类别的原始分数。
6. 通过 softmax 转为总和为 1 的分数，选择最高的若干项，并按权重中的类别顺序解释结果。

网络输出的第几个位置对应哪个类别，必须与训练一致。
例如第 2 个索引对应玫瑰时，预测阶段不能擅自改变类别排序。
同样，改变图片大小或归一化参数也可能使预测效果下降。

## 如何阅读结果

第一候选表示模型当前最倾向的类别，后续候选表示其他可能类别。
显示前三项时，它们的分数之和通常小于 1，因为另外两项没有显示。
分数未经校准，不能直接理解为“这个预测正确的概率”。

当前模型只能在雏菊、蒲公英、玫瑰、向日葵、郁金香之间选择。
输入未知花种或非花卉图片时，它仍会给出五类之一，当前不支持未知类别识别。
小规模检查模型的预测只用于验证代码，应使用充分训练的模型检验实际效果。

建议分别尝试数据集图片与自己拍摄的照片，并记录图片来源。
数据集内的图片示例不能代替外部场景测试；记录自拍照片上的正确和错误结果，有助于发现背景、角度和光照的影响。
