# 训练与验证

`src/train.py` 使用已划分的数据和手写 ResNet-18，从随机参数开始训练。
训练集更新参数，验证集比较每轮模型，测试集本阶段不读取批次、不参与模型选择。

## 一个批次怎样学习

```python
optimizer.zero_grad()
logits = model(images)
loss = criterion(logits, labels)
loss.backward()
optimizer.step()
```

1. 清空上一个批次的梯度，因为 PyTorch 默认累加梯度。
2. 前向计算得到 `[N,5]` 类别分数。
3. 使用交叉熵衡量分数与整数标签之间的误差，不提前计算 softmax。
4. 反向传播，计算各参数的梯度。
5. 优化器根据梯度更新参数。

一轮（epoch）表示遍历一次训练加载器；batch size 表示每批图片数量。
Adam 是本项目选用的优化器，学习率控制参数更新幅度。
默认学习率 0.001、权重衰减 0.0001；这些是实验起点，不保证最佳效果。

## 验证与指标

训练使用 `model.train()`，验证使用 `model.eval()` 并关闭梯度计算。
这也决定 BatchNorm 使用当前批次统计量还是训练时积累的统计量。
验证不会更新参数或 BatchNorm 的运行统计量。

loss 为按样本数加权的平均交叉熵，accuracy 为正确数量除以实际处理的图片数。
末批数量可能不同，不能简单把每批准确率或损失等权平均。
训练末批如果只有一张图片，会舍弃它，以免小尺寸下 BatchNorm 无法训练。
每轮实际处理数量保存在 `history.csv`，验证集始终完整遍历。

验证准确率提高时保存 `best.pt`；准确率相同则保留较早模型。
不要用测试集选择训练轮数、学习率或最佳模型。

## 输出文件

| 文件 | 内容 |
|---|---|
| `config.json` | 参数、实际设备与 PyTorch 版本 |
| `manifest.csv` | 本次使用的数据划分原样副本 |
| `history.csv` | 每轮训练与验证的损失、准确率、实际样本数和耗时 |
| `training_curves.png` | 随轮次变化的损失与准确率 |
| `best.pt` | 最佳模型权重、类别顺序、mean/std、配置、轮数和划分哈希 |

每次训练选择新的输出目录，程序拒绝覆盖已有目录。
`best.pt` 用于后续加载与预测，不包含优化器状态，所以当前不支持断点续训。
固定随机种子有助于复现实验，但不同硬件、软件版本仍可能产生不同结果。
只需保存结果的训练配置和权重；虚拟环境、图片和模型不会自动上传到代码仓库。

## 观察曲线

- 训练与验证损失都逐渐下降，通常表示模型正在学到有效信息。
- 训练损失下降，验证损失却持续上升，可能是过拟合，需要检查数据与训练方案。
- 单轮波动不能直接下结论，应结合多轮趋势和具体错误样例分析。
- 小样本、少轮数运行用于验证流程，不应当作最终分类效果。
